# Sereban-glitch-video-montage (v2.0.0)

Автоматизированный пайплайн монтажа видео для каналов и агентов OpenCode:
- **Короткие вертикальные видео (Shorts)**: 1080×1920, динамическая нарезка пауз, пиксельная подгонка двух/трёхстрочных субтитров, верхний титул, генерация вертикальной обложки.
- **Длинные горизонтальные записи (Long)**: 1280×720 / 1920×1080, транскрипция через Whisper large-v3-turbo (обход PyAV), умный аудит пауз, покадровый и посегментный рендер с защитой ОЗУ, создание глав (chapters), обложка.
- **Публикация**: YouTube Data API v3 (resumable upload, автоматическая установка обложки, проверка `channel_id`, строгий режим `private` по умолчанию).
